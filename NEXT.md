## Architecture notes

`apps/web/lib/api.ts` is the API seam. Pages call it, never `fetch` directly. Today it
resolves from `mock.ts`; when FastAPI lands, only the function bodies change and no page is
touched. `NEXT_PUBLIC_API_URL` selects the path, so it is a deploy-time env var.

`apps/web/AGENTS.md` is generated by `next dev` (verified: the generator ships at
`next/dist/server/lib/generate-agent-files.js`). It is gitignored as tool output.
